# Code de conduite

## Notre engagement

Nous voulons que ce projet soit un espace accueillant, respectueux et constructif pour toute personne qui souhaite apprendre, proposer une idée ou contribuer.

## Comportements attendus

- communiquer avec bienveillance et professionnalisme ;
- accueillir les points de vue différents et les retours argumentés ;
- se concentrer sur le problème et les solutions, jamais sur les personnes ;
- signaler les désaccords de manière constructive ;
- respecter la confidentialité et ne pas publier de données personnelles ou de données d'élèves.

## Comportements inacceptables

Le harcèlement, les attaques personnelles, les propos discriminatoires, les menaces, la publication d'informations privées et toute contribution volontairement malveillante ne sont pas acceptés.

## Signalement

Si un comportement pose problème, ouvrez une issue privée si le dépôt le permet, ou contactez directement les mainteneurs du dépôt en indiquant les faits, le contexte et les liens utiles. Les signalements seront traités avec sérieux et discrétion.

Les mainteneurs peuvent demander la modification ou le retrait d'un contenu et limiter la participation d'une personne lorsque cela est nécessaire pour préserver un espace de contribution sain.
