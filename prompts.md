## initial prompt :

je veux une application très simple en html css et javascript. Celle-ci aura pour projet d'améliorer l'assiduité de mes élèves. En faisant l'appel, les élèves présents gagnent 3 points, les élèves en retard de moins de 5min gagnent 1 point, ceux en retard de plus de 5min ou absents n'en gagnent aucun.
sur l'appli on doit pouvoir :

- ajouter des personnages/élèves
- modifier leur nombre de points avec précision de la date
- consultater le classement général
- tout sauvegarder dans le localstorage avec possibilité de créer une sauvegarde et de la charger si besoin.

Je veux que cela s'inspire d'une ligue de football pour motiver les élèves en prenant un domaine qu'ils apprécie.
Garde une base de code propre, avec des fichier ne dépassant pas 300 lignes avec plusieurs fichiers séparés si besoin. Il faut que ce soit pédagogique car ils seront amenés à étudier le projet et à l'améliorer.

## second prompt :

j'aimerais que d'autres enseignants fasse leur propre classement. Du coup je vais rendre disponible l'application sur le web, et j'aimerais :

- que le titre de la ligue puisse être changé pour que chaque enseignant choisisse le sien. Ce tite devra être conservé dans le local storage
- que la couleur principale puisse également être changée pour que chaque enseignant choississe la sienne
- ajouter le nom du coach (qui sera du coup l'enseignant), également stocké dans le local storage
